## Every static form and input

Numeric/date/text: valid, blank, malformed, length/boundary/precision violations as applicable, then correction/retry. Required blanks must fail; optional blanks follow documented defaults. Selects: exercise every listed value and reject unsupported submitted API values. Checkbox/radio: exercise both states/all choices; invalid text is not applicable. Sliders: minimum/middle/maximum, amount synchronization and responsive dragging. Read-only outputs: inspect/copy accurate text; invalid user input is not applicable. Do not use private addresses, phone numbers, payment details or real passwords.
